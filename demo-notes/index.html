Group 9 · Gemma 4 Developer Agent Competition (Kaggle) · running Gemma 4 12B locally on an RTX 5070 Ti

How the agent works

Read bug report→ A Search code→ Edit fix→ B Run tests, retry if failed (max 3)

What to say

  1. Our agent searches the code first, then fixes, then tests and retries.
  2. Search works on real bugs: Gemma finds the right file first 80% of the time vs 58% for the standard method.
  3. The full agent already fixes a bug end to end on a small project.
  4. Correction: the competition allows the 12B model, not only 31B as in our proposal.
